# Bowling ball references

Upload photos here to guide the ball artwork. Use the reference for the specific team and era when choosing a logo, matching colors, or placing a design on the ball.

- [Team logos](team-logos/) — the preferred mark for each team's logo ball, including Tampa Bay.
- [Team designs](team-designs/) — uniforms, alternate marks, patterns, and team history for each club's second ball.
- [Rays specials](rays-specials/) — inspiration for the four additional Tampa Bay designs.

Open a folder and choose **Add file → Upload files**. If an image has several details, a filename like `TB-1998-sleeve-patch-colors.jpg` helps identify the one you want to use.
